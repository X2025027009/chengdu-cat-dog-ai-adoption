# 成都猫狗小院

成都猫狗小院的领养平台，面向访客提供宠物档案、领养申请与 AI 匹配，面向管理员提供档案维护、申请审核辅助与通知。

参赛方向：2026 第九届传智杯全国大学生数智创新与 AI 应用大赛 · [AI创新应用挑战赛](https://www.boxuegu.com/matchTrack/detail/?id=10039)。作品展示应用内 AI，也说明负责人如何表达意图、审阅预览、约束并纠正 AI 编程。

历史线上入口：[成都猫狗小院](https://chuanzhibei-d3gvmowp1e63d7f33-1470251683.tcloudbaseapp.com/)。本轮仅验收本地源码，没有验证线上版本；WebP 素材与脚本须由委托方审核后整体同步，不能只上传 HTML。

## 这是什么

咨询通常需要反复确认住所、家庭意见、陪伴时间与养宠经验。访客先查档案和条件，再提交申请；管理员根据原始资料与 AI 提示沟通，最终决定是否领养。没有实测数据证明平台已提升领养成功率，因此不将目标写成效果结论。

基础版本同样由负责人借助 Codex 开发。已恢复的需求对话始于 2026-08-17，当前 Git 最早代码快照为 2026-09-06。两者不是逐步一一对应的记录，不将早期快照包装成完整提交链。之后由负责人引导 Codex 与 Harness 持续完善业务、AI、工程规范及界面。

## 本地运行

### 十分钟复现路径

先从委托方提供的真实仓库地址获取代码；这里不虚构公开仓库 URL。建议使用 Node.js 24 LTS 与 npm，依赖版本以 `package-lock.json` 为准。

```bash
node --version
npm --version
npm ci
npm run preview:local
```

打开 <http://127.0.0.1:4173/>。端口占用时，在 PowerShell 使用：

```powershell
$env:PORT = '4177'
npm run preview:local
```

预览服务仅监听本机，通过白名单提供页面、脚本、样式与 `assets/`。不要用通用服务器公开仓库根目录，避免暴露配置、Git 和内部文件。建议通过 HTTP 预览，而不是直接双击 HTML。

十分钟是赛事目标，本轮未在全新机器计时，不保证所有网络条件都能达成。依赖安装需要网络；安装后的 `npm test` 完全离线。创建云资源、数据库和配置真实模型不包含在静态预览路径内。

### 审核模式的范围

本机地址与 `file:` 自动启用审核模式：不加载 CloudBase SDK、不连接业务云端，使用示例档案与浏览器本地草稿。可审阅七页、筛选、照片抽屉、表单与按钮反馈；申请提交被阻断，草稿不会同步线上。

真实匹配、图搜、管理员 AI 与语音识别在本地停用。外部字体和示例图片仍可能联网，因此审核网页不等于所有资源离线。不支持原生跨文档转场的浏览器仍可正常跳页。

本地预览不需填写 `.env`。真实服务配置见 [环境模板](.env.example)；浏览器不会自动读取该文件。

## 技术架构

```text
七个原生静态页面
  ├─ CloudBase 会话及公开读路径 → PostgreSQL RLS
  ├─ 业务网关 → yard-api → 申请、管理校验、群通知
  └─ HTTP → ai-stream → SSE 与有界工具循环
                       ├─ DeepSeek 对话
                       ├─ knowledge.js → 文本向量与 pgvector
                       └─ vision.js → 视觉向量与站内照片
```

`yard-api` 为 Event 云函数；`ai-stream` 为 HTTP 云函数，以 SSE 逐步返回回答与查询状态。AI 不可用不应阻断人工查看档案和处理申请。配置的云函数运行时为 `Nodejs20.19`，不等于本地工具环境。

数据库演进以 `cloudbase/migrations/` 为准，网关策略在 `cloudbase/policy/`。匿名权限不能直写申请，管理动作在服务端校验管理员并走特权通道。自助修改使用随机令牌，数据库只存哈希且限制有效期；通知不得泄露内部备注、令牌和来源标识。

模型 Key、机器人地址及平台临时凭据不进入公开源码。CloudBase `role: anon` 的可发布密钥不是管理密钥。

## AI 能力与边界

访客助手可调用六个工具：`search_knowledge`、`search_pets`、`get_pet_profile`、`get_adoption_policy`、`get_follow_up_history`、`check_requirement_gaps`。工具返回公开资料而非申请人信息；循环最多三轮，最后一轮不再提供工具。缺口工具检查是否说明关键信息，不等于替人判断是否合格。

文本 RAG 按档案、要求、政策与回访切块，每块最多 600 字符；查询前检查索引新鲜度，过滤相似度低于 0.3 的片段并提供来源。索引可能调用模型并写数据库，不能视为无副作用的只读探针。服务失败时返回明确降级信号，不承诺并发更新下永远没有陈旧数据。

管理员审核 Agent 提供摘要、缺口和建议追问，不自动修改申请状态。规则兜底与模型生成须区分，不能把失败生成包装成模型结果。

照片理解只生成可编辑的外观初稿，不推断疾病、疫苗或绝育。以图搜宠比较视觉相似度，不是身份鉴定或领养适配性证明。照片先在浏览器压到最长边 768px；访客查询图不写入对象存储，但会发往模型服务。服务端取站内图片时校验域名及数据库路径。

语音输入使用浏览器 Web Speech API，识别结果先进入输入框，由人确认发送；不支持时隐藏或停用入口。浏览器可能使用远程识别服务，不宣称语音完全在本机处理。
